# Academia Aura — HTML + CSS + JavaScript

Esta é a versão experimental da Academia Aura sem React/TypeScript.

## Estrutura

- index.html → estrutura das páginas
- style.css → aparência e responsividade
- script.js → navegação, dados e funções

## Objetivo

Este repositório foi criado para testar a migração do projeto React para uma estrutura mais simples e familiar:

HTML + CSS + JavaScript.

A versão original em React permanece separada no repositório Academia---Hackathon.

## Estado atual

A primeira versão já possui:

- Tela de login/demonstração
- Dashboard
- Treinos
- Alimentação
- Evolução
- Perfil
- Aura
- Navegação sem recarregar a página
- Dados locais com localStorage
- Gráfico visual simples

A próxima etapa pode conectar Firebase Authentication, Firestore, App Check e Gemini sem voltar ao React.
